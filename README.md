# Tandil Tech Week - Rediseño Hackathon

Sitio web moderno y responsivo para la Tandil Tech Week, creado para un hackathon.

## 📋 Descripción

Rediseño de la página web oficial de Tandil Tech Week, un evento que conecta a la comunidad tecnológica de Tandil. El sitio incluye:

- **Hero section** con llamada a acción principal
- **Agenda de eventos** (talleres, charlas, hackathon)
- **Nuestros hablar** con perfiles deponentes
- **Sección de inscripciones** con formulario
- **Pie de página** con enlaces rápidos

## 🛠️ Tecnologías Utilizadas

- HTML5 semántico
- CSS3 con variables personalizadas y Flexbox/Grid
- JavaScript vanilla para interacciones básicas
- Font Awesome para íconos
- Google Fonts (Segoe UI)

## 🚀 Cómo Empezar

1. Cloná el repositorio
2. Abrí `index.html` en tu navegador
3. Personalizá el contenido según necesites

## 📁 Estructura del Proyecto

```
proyecto-tdw/
│
├─ index.html        # Página principal
├─ style.css         # Estilos visuales
├─ script.js         # Lógica y interacciones
├─ README.md         # Esta documentación
└─ (otros assets)
```

## 🎯 Para el Hackathon

- Personalizá el contenido con la información real del evento
- Cambiar los colores si tenés una identidad visual definida
- Agregar más secciones según sea necesario (patrocinadores, ubicación, etc.)
- Optimizar las imágenes y contenido para mejor rendimiento
